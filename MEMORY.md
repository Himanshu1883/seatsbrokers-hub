# MEMORY.md

SeatsBrokers is a marketing site for a B2B ticketing infrastructure platform — brokers list and price inventory across marketplaces; travel partners search the same inventory, add margin, and share branded quotes. The app is TanStack Start (React 19 + Vite) with a single global stylesheet (`src/styles.css`, Tailwind v4) and shared copy in `src/content/site.ts`. The homepage is a long landing narrative; `/brokers`, `/travel-partners`, `/marketplace-connectivity`, `/event-intelligence` and `/api` are the deep product pages with live consoles; remaining routes are still PageHero + FeatureGrid/WorkflowSteps shells.
